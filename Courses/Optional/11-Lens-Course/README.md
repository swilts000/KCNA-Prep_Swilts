# Lens - Kubernetes IDE Course

## 📚 Course Overview
Lens is the most popular Kubernetes IDE, providing a powerful desktop application for managing clusters visually. This course teaches you how to use Lens for development, monitoring, and multi-cluster management.

## 🎯 Key Features
- Desktop application (Mac, Windows, Linux)
- Visual cluster management
- Built-in terminal and kubectl
- Prometheus metrics integration
- Multi-cluster support
- Extensions and plugins

## 📋 Planned Labs (15 total)
- Lab 1.1: Installing and Configuring Lens
- Lab 1.2: Adding and Managing Clusters
