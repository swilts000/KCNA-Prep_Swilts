# KCNA-PREP
Prep for KCNA

## Running locally (quick)

To view the apps in a browser, run a simple local HTTP server from the project root.

Using Python 3 (recommended):

```powershell
cd C:\Users\xwilt\OneDrive\Desktop\KCNA-Prep_Xwilt47
python -m http.server 8000
```

Open in your browser:
- Flashcard app: http://localhost:8000/index.html
- Learning app: http://localhost:8000/Chapters/learning-app/index.html

Other options:
- Node (serve): npx serve
- VS Code: Live Server extension (right-click index.html → Open with Live Server)

Notes:
- Server runs on port 8000 by default. Stop it with Ctrl+C in the terminal where you started it.
- If Python is not available, use one of the alternatives above.
